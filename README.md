# 🦿 Система бронирования отелей
Консольное приложение для учёта бронирования номеров в отеле. Данные сохраняются в SQLite.

## 🤔 Цель проекта
Учебный и портфолио-проект: демонстрация работы с БД, консольным UX.

## 🌟 Возможности
- Добавление, удаление и редактирование броней.
- Заказ еды себе в номер с изменением стоимости проживания в реальном времени.
- Просмотр всех забронированных номеров или конкретно введённого.

## 💻 Стек
- С++22
- MSVC (Visual Studio Build Tools / Community)
- SQLite

## 🕹️ Работа с приложением
- Главное меню: бронирование, просмотр броней, заказ еды.
- Все действия выполняются через подсказки в консоли, изменения сохраняются сразу

## 🎮 Логика расчёта
- **Цена бронирования:** учитывается комната бронирования и в зависимости от неё умножается на число.
- **Цена еды:** учитывается комната заказа и начальная цена заказа умножается на число.

### 🤖 SQLite
- Файл БД: `hotel.db` (создается автоматически)
- Таблицы:
  - `RECORD(id, name, age, number, days, price)`
 
## ⛔ Ограничения
- Нет проверки при перезаписи несуществующего номера
